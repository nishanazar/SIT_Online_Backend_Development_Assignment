# JavaScript Advanced Arrays & Objects — Assignment 07

Advanced Array Methods, Sorting, Searching, Objects, and Methods.

## Topics Covered
- Array Searching & Finding: `includes()`, `indexOf()`, `lastIndexOf()`, `find()`, `findIndex()`, `findLast()`, `findLastIndex()`
- Array Sorting & Reversing: `sort()`, `reverse()`, `slice()` for immutable operations, and random sorting
- Array Manipulation: `concat()`, `slice()`, `splice()` and Arrow Functions
- JavaScript Objects: Object creation, dot notation vs bracket notation, adding, updating, and deleting properties
- Object Methods & `this` Keyword: Defining methods inside objects and utilizing `this` context

## Questions

1. **Array Searching & Finding** — Students array analysis using modern search and find methods.
2. **Array Sorting & Reversing** — Prices array sorting (ascending, descending, reverse, random order).
3. **Array Manipulation & Analysis** — Combining, slicing, splicing marks array and summarizing via arrow functions.
4. **Object Basics & CRUD** — Employee object creation, property access, addition, updating, and deletion.
5. **Object Methods & `this`** — Adding behavior (methods) to employee objects using the `this` keyword.
