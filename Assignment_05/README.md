# Assignment 05

Four JavaScript practice projects.

### Projects
- **Q1-Calculator:** `Q1-Calculator/index.html` - A simple calculator for basic arithmetic operations.
- **Q2-Functions:** `Q2-Functions/index.html` - Demonstration of JavaScript function declarations and invocations.
- **Q3-Loops:** `Q3-Loops/index.html` - Examples of using `for`, `while`, and `do...while` loops.
- **Q4-RollCall:** `Q4-RollCall/index.html` - A script to manage a list of attendees.

*Run:* Open the respective `index.html` file in your browser. Check the browser console (F12) for functional output.
