# SIT Online Backend Development - Assignment 13

This repository contains two Node.js & Express REST API projects built using strict MVC architecture as per Assignment requirements.

---

## 1. Employee Task Management (Question 1)
- **Folder:** `./employee-task-management`
- **Port:** 3000
- **Description:** REST API for managing employee tasks with CRUD operations, status/priority filters, search, summary, and overdue tracking.
- **Run:**
  ```bash
  cd employee-task-management
  npm install
  npm start
  ```

---

## 2. Library Management (Question 2)
- **Folder:** `./library-management`
- **Port:** 4000
- **Description:** REST API for managing library books with CRUD operations, title search, and availability filtering.
- **Run:**
  ```bash
  cd library-management
  npm install
  npm start
  ```
